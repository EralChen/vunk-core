GlobalRenderer ​

GlobalRenderer 是一个全局渲染容器组件，提供统一的内容渲染点，允许你将内容从组件树的任何位置动态渲染到指定位置。

基本概念 ​

GlobalRenderer 本质上是一个单例的内容容器：

  • 通过 slots: preset 可以预设全局渲染的位置和外观
  • 配合 GlobalRendererTemplate 组件控制内容的动态显示
  • 任意时刻只有一个 GlobalRendererTemplate 被激活并渲染

使用场景 ​

GlobalRenderer 适用于多种复杂的 UI 交互场景：

  1. 上下文工具栏/菜单 - 在特定元素附近显示工具栏或菜单
  2. 浮动编辑面板 - 在点击元素时显示编辑面板
  3. 全局通知/提示 - 统一管理应用中的通知和提示
  4. 动态内容预览 - 在不改变布局的情况下预览内容
  5. 向导/引导界面 - 在界面上显示引导信息
