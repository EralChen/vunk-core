SegmentRenderer ​

SegmentRenderer 是一个灵活的分段渲染组件系统，它允许你将内容分割成多个段落，然后在视图中以自定义的方式渲染这些段落。

组件概述 ​

由三个主要组件组成：

  1. SegmentRenderer：容器组件，初始化上下文环境
  2. SegmentView：视图组件，控制如何渲染所有已注册的段落
  3. Segment：核心组件，定义各个段落的内容和属性

基本用法 ​

在上面的示例中，创建了一个标签页界面，每个 Segment 定义了一个标签页的内容。

应用场景 ​

在 Tabs 的用例中，通过 Segment, 每个标签页的内容可以独立定义，从而保持 Tab 高内聚。扩展 Tab 时，可以直接添加新的 Segment，而不需要再关心 Tabs 中的内容。

另外，这让 Tab 内容与 TabPane 组件解耦，使之可以灵活地被封装到其他组件中。

这种分离渲染内容和渲染方式的设计使得组件非常灵活，可以适应多种场景。

工作原理 ​

  1. SegmentRenderer 创建一个上下文环境，并通过 Vue 的 provide/inject 机制共享给子组件
  2. 每个 Segment 组件将自己的 slots 和 attrs 注册到这个上下文中的 items 数组
  3. SegmentView 可以访问这个上下文，并使用它来渲染所有注册的段落

API ​

SegmentRenderer ​

容器组件，无特殊 props。

vue
<SegmentRenderer>
  <!-- 内容 -->
</SegmentRenderer>

SegmentView ​

视图组件，控制如何渲染所有已注册的段落。

vue
<SegmentView>
  <template #default="{ items, attrs }">
    <!-- 自定义渲染逻辑 -->
  </template>
</SegmentView>

Slots ​

名称描述插槽参数
default默认插槽{ items, attrs }
  • items：所有已注册的 Segment 组件的信息数组
  • attrs：SegmentRenderer 的属性

Segment ​

核心组件，定义各个段落的内容和属性。

vue
<VkSegment
  name="segmentName"
  label="显示标签"
  :other-prop="value"
>
  <!-- 段落内容 -->
</VkSegment>

Props ​

所有传递给 Segment 的 props 都会被收集到 items 数组中的对应项的 attrs 对象里，可以在 SegmentView 中使用。

Slots ​

所有 Segment 的插槽都会被收集到 items 数组中的对应项的 slots 对象里，可以在 SegmentView 中使用。

进阶用法 ​

自定义 Key ​

SegmentRenderer 组件系统允许通过自定义 key 创建多个独立的上下文环境，适用于在同一页面需要多个互不干扰的 SegmentRenderer 的场景。

ts
import { createSegmentRenderer } from '@vunk-core/components/segment-renderer'

// 创建一个自定义的 SegmentRenderer
const customKey = Symbol('custom-segment')
const {
  SegmentRenderer: CustomRenderer,
  SegmentView: CustomView,
  Segment: CustomSegment
} = createSegmentRenderer(customKey)

然后可以在模板中使用这些自定义组件：

vue
<CustomRenderer>
  <CustomView>
    <!-- 自定义渲染逻辑 -->
  </CustomView>

  <CustomSegment>
    <!-- 段落内容 -->
  </CustomSegment>
</CustomRenderer>
