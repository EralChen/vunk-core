ScaleContainer ​

缩放容器组件，用于将内容按比例缩放以适应容器大小，类似于 CSS 的 object-fit: contain 效果。

功能特性 ​

  • 🎯 比例保持：内容按设计尺寸比例缩放，不会变形
  • 📐 自适应缩放：自动计算最佳缩放比例，确保内容完全显示
  • 🔄 响应式设计：容器尺寸改变时自动重新计算缩放

使用场景 ​

  • 大屏可视化项目的自适应布局
  • 固定设计尺寸的组件在不同容器中的展示
  • 需要保持宽高比的内容缩放
  • 响应式设计中的比例适配

基础用法 ​

外层容器会撑满父级元素，内部内容按照指定的设计尺寸进行等比缩放。

响应式效果 ​

演示相同设计尺寸的内容在不同容器尺寸下的自适应缩放效果。

大屏可视化示例 ​

展示在大屏可视化项目中的实际应用场景，可以通过切换容器尺寸查看缩放效果。
